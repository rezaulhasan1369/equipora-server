## Findings and corrections

1. **Catalog navbar mismatch:** the catalog hero is the existing body surface, not a separate gradient. Dark F6 CSS painted the full-width header pseudo-element rgba(20,39,54,.97), with a visible #567086 border, over the #101f2b body. The new catalog route marker is set only for the exact /equipment pathname. Its expanded dark pseudo-element uses the same shared body-surface token and a transparent bottom border. Expanded content bounds, full-width wrapper, floating background/border/shadow, 112/80px hysteresis, timing and reduced-motion rules remain unchanged. Homepage, details, login and dashboard header surfaces keep their existing rules. Light mode is unchanged.
2. **Rental price:** the original #263c51 !important declaration overrode dark paragraph text. Against #101f2b it provided 1.47:1 contrast. A dark-only override uses the existing --color-base-content (#e6eef5), giving 14.30:1. Amount size, unit text, hierarchy and all calculations are unchanged.
3. **Mobile comparison tray:** added a native keyboard-operable minimize/expand button below 768px, with aria-expanded and controlled-region IDs. Minimizing hides the message/items/actions and retains the selected IDs. Desktop presentation and the three-item limit are unchanged. Pagination is explicitly exercised while minimized. During accessibility testing, the existing selected Compare button also failed WCAG label-in-name because its visible Selected text was absent from its accessible name; the name now includes selected while preserving the equipment name and pressed state.
4. **Booking modal:** the existing form already scrolls inside a bounded 90dvh panel. Full-page screenshots exaggerated its height, but there was a real defect: the absolute close button scrolled outside the viewport (observed y≈-840 at 375×667). The title and close button now form a sticky, opaque heading within the same scroll container. No fields, validation, quotes, Checkout requests or fulfillment logic changed. Tests fill every field, reach the enabled Checkout action without submitting it, verify heading/close visibility after scrolling, close with the button and verify restored Book now focus. Existing Escape/focus regressions also pass.
