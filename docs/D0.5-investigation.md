## Hosting assessment

Keep Netlify until the failure category and production configuration are known.
Its default function egress addresses fluctuate; static egress via Private
Connectivity is an Enterprise add-on, unavailable as a Netlify Free solution.
Broad cloud-provider CIDRs and a one-time observed function IP are not reliable,
least-exposure substitutes. Do not automatically broaden the Atlas list.

If stable egress proves necessary, an OCI Always Free VM is a candidate: run the
existing Express API on the VM, use its public egress address, and seek separate
approval for an Atlas /32 entry. This preserves MongoDB but requires an approved
backend-host migration, Linux updates, HTTPS, supervision and monitoring. Free
capacity may be unavailable and idle instances can be reclaimed; it is not an
unconditional production reliability guarantee. Confirm all selected resources
remain inside current free limits before provisioning anything.

An existing trusted server with stable egress may avoid new hosting spend, but
availability and administration depend on that host. A development laptop is
unsuitable for reliable production hosting. Koyeb does not publish guaranteed
static outbound IPs, so moving there alone would not resolve this requirement.
No secure, continuously free option with guaranteed production availability has
been established. Do not promise one or migrate on the basis of a timeout.
